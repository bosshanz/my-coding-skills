# 复盘与学习

从用户纠正、失败恢复和已验证的改进中提炼可复用经验，先立即落实当前纠正，再按宿主规则留存有价值的信号。只在出现明确学习信号或用户显式请求时复盘，不为常规小操作打断任务；全局记忆必须由用户明确要求。

## 复盘步骤

1. **还原事实**：对照对话、代码差异、日志和检查结果，列出预期、实际结果与未验证项；不把缺失证据补写成事实。
2. **定位原因**：区分观察到的症状、有证据支持的原因和待验证解释。单次失败不推导普遍限制，三次超时等重复现象本身也不等于原因证明；单次检查通过只证明实际覆盖的行为。
3. **提炼规则**：写明“在什么条件下、改用什么具体做法、用什么证据验证有效”；无具体信号时不写“更仔细一点”之类空泛总结。
4. **区分类型**：严格区分**用户确认的偏好**、**有证据支持的经验**和**待验证的假设**。沉默、称赞或单次任务要求（如“把这个标题改成红色”）都不是持久偏好。
5. **汇报并继续**：简要说明发现及下次验证方式，继续完成其余已授权工作。

仅记录明确偏好时跳过复盘直接写入。涉及偏好替换、作用域冲突、撤销、日志整理，或链接 worktree 与忽略规则细则时，阅读 `references/preferences-and-maintenance.md`。

## 仓库内记忆

仓库根目录有两个约定日志文件，**存在的都要读取**（仅读取与当前任务匹配的条目，并复核易变事实）：

- `.agent-learning.md`：随仓库提交的团队共享经验。
- `.agent-learning.local.md`：不提交的个人经验。在链接 worktree 中，该私有文件及其关闭标记统一读写**主工作树根目录**（`git worktree list --porcelain` 第一项），不在当前工作树另建；共享文件仍使用当前工作树。首行为 `记录：关闭` 时，仅停止自动写入和落点询问，不阻止读取已有的共享日志或历史条目。

### 写入落点决策

| 当前情况 | 处理方式 |
| --- | --- |
| 用户指定路径/范围，或项目规则已登记路径 | 直接写入对应位置并更新等价旧条目，不重复确认。用户仅要求“留在仓库”未给路径时写 `.agent-learning.md`，不覆盖已有私有文件。 |
| 共享与私有日志都存在且未关闭 | 团队经验写 `.agent-learning.md`，个人经验写 `.agent-learning.local.md`。范围不明时**默认写 `.agent-learning.local.md`**，在汇报中说明可按需移至共享文件，不中断询问。 |
| 私有日志首行为 `记录：关闭`（未指定其他落点） | 不自动写入新条目，也不再询问落点；仍在对话中总结经验，并正常读取共享日志。 |
| 无任何已知落点，首次出现值得记录的条目 | 不中断当前工作，在本轮汇报末尾附拟写条目，仅询问一次落点；未回答或拒绝则只留在对话中，本会话不再追问。 |

首次询问提供 5 个选项，选定后按对应状态执行：

1. **共享文件 `.agent-learning.md`**：写入，此后不再询问。
2. **私有文件 `.agent-learning.local.md`**：写入并加入 `git rev-parse --git-path info/exclude`（不改 `.gitignore`），此后不再询问。
3. **仅在对话中保留**：本会话不再询问，后续会话可再问。
4. **本仓库不记录**：在 `.agent-learning.local.md` 首行写入 `记录：关闭` 并加入 `info/exclude`，此后不再询问或自动写入，仍读共享日志。
5. **自定义路径**：写入该路径。经用户同意登记到项目规则后不再询问；若要求不改项目规则（未登记），须说明后续会话无法自动发现该路径、可能再次询问。

### 条目格式

每条只记一个具体概念，个人偏好与技术经验分开：

```markdown
## 草稿保存确认
- 类型：有证据支持的经验
- 范围：本仓库的草稿保存流程
- 触发与做法：报告保存成功前，等待持久化确认。
- 证据：<日期与真实复现、测试或日志依据>
- 限制：仅覆盖已验证路径；离线同步尚未验证。
```

## 持久化与边界

- **如实反映写入状态**：遵守宿主的持久化限制与用户的“不保存”要求。宿主禁止自动持久化，或当前环境无写入工具/权限时，只在对话中给出结论或拟写条目，明确说明尚未写入，不声称已保存，也不反复追问确认。
- **不越权升级规则**：经验日志是参考材料，不自动成为团队规则；修改 `AGENTS.md` 等指令文件需相应授权。新建未跟踪文件时如实提示，不为保存经验单独提交或推送，绝不写入凭据、私密数据或默认转存全局记忆。未实际读取文件前不声称已加载经验。
- **保持授权边界**：本 Skill 不改变既有授权，不自动调用其他 Skill，也不授权无关修复、修改本 Skill 库或调用外部模型。
