# 设计方向

依据用户任务、真实内容、既有设计系统和平台惯例确定视觉层级与设计语言。全新概念页可突出鲜明辨识度；已有产品与高频工具优先保证连续性、扫描效率和易操作性。

## 方向与视觉基本功

首屏优先呈现当前任务最核心的主张、内容或操作；仅在内容确有先后顺序时才加数字编号，表现性装饰集中在核心主题区域，不铺满全页。

- **层级与密度**：决定“先看什么 → 比较什么 → 操作什么”。高密度工具收紧间距但保留清晰分组与点击热区；展示型页面放宽留白突出重点。
- **网格与窄屏重排**：标题、正文、控件和数据列共享少数明确对齐线；窄屏按阅读与操作优先级重排容器，不机械等比压缩桌面版。
- **字阶与中英混排**：拉开标题、正文、辅助说明与数据的层级，用真实内容检查中英文混排换行、标点、超长词与数字对齐；个性展示字体仅限短标题。
- **色彩与图像角色**：明确背景、表面、正文、边框、主强调与状态反馈色，不单靠颜色传达报错或选中；配图呈现真实产品或场景，省去无信息量的装饰插画与图标。

## 对齐与细节测量

- **对齐准则**：复用已有对齐线，不随意另起边缘；图标配文字、播放三角形等不对称图形采用**光学居中**；并列卡片与同行输入框/按钮统一高度、内边距和圆角；嵌套容器内边距不挤偏外层对齐线；表单标签列与输入列各自对齐。
- **几何核查**：在目标最宽/最窄视口填入超长文本与空状态渲染，用 `getBoundingClientRect`、开发者工具或原生布局检查器实测间距与坐标，修正同级元素间无意的 1–4px 偏差，不单凭肉眼扫截图下结论。
- **极端内容溢出与占位**：关键识别信息（报错原因、金额、路径/ID 尾部）优先换行或首尾保留截断，不盲目单行尾部省略（`truncate`）且不留查看全文途径；Flex/Grid 子项显式设置最小收缩边界（如 `min-w-0`）防长串撑破布局，异步图片与媒体预留固定宽高比占位防布局偏移。

## 视觉参数起点与硬下限

无既有设计系统时可从下表起调（已有设计系统与平台规范优先）：

| 项目 | 调校起点 | 调整依据 |
| --- | --- | --- |
| 正文字号 | 阅读页 16–18px；高密度工具 13–14px；辅助文字 ≥ 12px | 阅读距离、密度与系统文字放大后的排版表现 |
| 行高 | 中文正文 1.6–1.8，西文正文 1.4–1.6，标题 1.2–1.4 | 字号越大、行宽越短，行高越小；防多行标题挤压或松散 |
| 行长 | 中文每行 25–40 字，西文 45–75 字符 | 过宽时限制容器最大宽度或分栏，不靠缩字号凑行 |
| 字阶与字重 | 4–6 级字号、2–3 种字重 | 现有层级不够表达关系时才新增 |
| 间距节奏 | 4px 或 8px 倍数阶梯；组内间距 < 组间间距 | 逻辑关系变化才跨档调整，不逐处随手填数 |
| 嵌套圆角 | 2–3 级圆角；内层圆角 ≈ 外层圆角 − 间距（≤ 0 则取直角） | 内外同圆角会让边角显得臃肿 |

**不随风格或品牌偏好妥协的硬下限：**

- **对比度下限**（[WCAG 2.2 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)）：正文与背景对比度 **不低于 4.5:1**，大号文字（≥ 24px 或 ≥ 18.5px 粗体）及控件边框/图标不低于 **3:1**（含占位符、悬停和聚焦态），须用工具实测色值。若品牌希望营造“轻盈感”，应通过加大留白、减轻边框、调整字重或将浅灰加深至达标色值来实现，绝不接受低于 4.5:1 的浅灰正文。
- **命中目标尺寸**（[WCAG 2.2 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)）：指针点击热区不小于 **24×24 CSS px**（或留出等效安全间距），触屏主界面按平台规范取 **44pt / 48dp**；视觉图标可小，热区不能缩。

**高复用视觉取舍**（产品另有明确规范除外）：

- **先降次要，再提主要**：重点不突出时先减弱周边元素的对比度、字重或边框，而非一味放大加色。
- **每区单一主操作**：其余降为次要或文字按钮；危险操作靠文案与语义色警示，不抢主按钮默认焦点。
- **用留白和对齐分组**：能靠间距分清关系的，不叠分隔线、描边、底色框和阴影。
- **克制使用强调色**：中性色承载大面积界面，强调色留给关键操作与状态。
- **数字按数字排**：纵向对比列使用等宽数字（`tabular-nums`）、右对齐、统一小数位与单位。
- **深色主题重调层级**：用表面明度差而非加深阴影表达前后层级，降低大色块饱和度并重测对比度。

## 一致语言、克制与界面文案

- **绑定语义 token 与克制阴影**：先吃透现有色彩语义、控件全状态样式与动效节奏，已有系统时优先绑定语义化颜色 token 而非散落硬编码色值；表面分层优先靠细微明度差或低透明度同色系细边框，慎用厚重黑灰投影。缺少约束时避免无理由套用泛滥模板（泛用紫蓝渐变、万物套卡片、居中大图配三张特性卡、用 emoji 冒充功能图标）。
- **平实写作**：用用户的领域词汇代替内部实现词（写“通知”而非“webhook 配置”），按钮直接写动作结果（如“保存更改”），报错与空态写明原因和下一步可执行操作，并放进真实窄屏检验换行与截断。

## 选择示例与成对案例

- **营销概念页**（如野外录音专题）：选一种贴合主题的摄影与短标题字体建立焦点，不在每张卡片重复贴通用声波装饰。
- **既有管理后台**：保留原有字体、导航和控件，集中精力做好批量操作逐项状态与失败重试，不靠换字体解决效率问题。
- **原生桌面设置**：遵循系统控件与窗口缩放习惯，省去花哨首屏和冗长入场动画。

### 成对案例：同一“野外录音档案”首页，有无既有品牌约束

固定条件：桌面与手机双端首页，标题“听见城市边缘”、导语及三条带地点与时长的可播放录音，核心任务是发现并点击播放；仅改变是否存在必须沿用的品牌系统。

| 约束条件 | 具体方案与理由 | 代价、改判条件与验证重点 |
| --- | --- | --- |
| **无既有品牌约束** | 用录音地实景照片与具辨识度的短标题建立氛围，首屏直接给首条播放入口，下方用干净列表对齐地点、时长与播放键；声波仅在真实播放进度处出现。 | 依赖高质量实景图与窄屏裁切控制；若用户转为高频检索条目，则收紧首屏改为搜索加紧凑列表。实测双端图文对比度、裁切及点击播放链路。 |
| **有既有品牌约束** | 沿用品牌既定的深蓝主色、无衬线字阶、圆角控件与播放键状态组织同一批内容，靠品牌摄影与声音内容体现特色，避免另造字体和容器造成割裂。 | 首屏个性受组件限制，长元数据可能撑破既有卡片；若出现换行或状态难辨，先在品牌规范内调密度，确无法满足再提局部变体。实测双端换行、对比度与按钮状态。 |
