# 动画

用于微交互、浮层进出、路由切换、手势拖拽及动效审查。先明确运动能帮用户看懂什么关系或反馈；若去掉动画不影响理解且让操作更快，就不加。

## 动效判断六步

按需梳理影响当前任务的部分，无需输出固定清单：

1. **目的与频率**：是确认输入、交代空间来源，还是低频氛围？高频连续操作（如快捷键切换、密集筛选）优先即时响应，避免每次等待动画播完。
2. **变化对象**：只让真正改变的局部元素运动，导航栏、背景列表等不变内容保持静止。
3. **前后状态**：明确触发前、进行中、完成、失败与取消时的可见状态及何时允许下一步操作。
4. **时序与空间**：弹出层沿触发点方向进出，前进与返回方向互为镜像；退出通常比进入更快，优先归还下层可操作状态。
5. **中断衔接**：快速反向、连点开关或中途取消时，必须从**当前呈现的计算位置/透明度**直接转向新目标，绝不跳回第一帧重播或排队等待。
6. **静态替代**：开启“减少动态效果”时关闭非必要位移、缩放与循环，靠边框、文字、图标、选中态和焦点迁移完整传达结果。

## 参数起点与手势规则

无既有规范时可按以下范围起调（以正常速度下的真机/目标视口表现为准）：

| 变化类型 | 时长起点 | 缓动与曲线取舍 |
| --- | --- | --- |
| 按压、开关等即时反馈 | 100–180ms | 快起慢收（ease-out），连点无需等待播完 |
| 下拉菜单、气泡、小浮层 | 150–250ms | `transform-origin` 贴近触发侧；遮罩淡入淡出与主体位移分开计时 |
| 侧栏、面板或大区域转换 | 200–400ms | 屏内移动用两端平缓曲线；路由切换预留加载占位防布局跳变 |
| 拖拽释放、可连续接管手势 | 弹簧响应约 0.3–0.5s | 含文字与精确点击目标时严控或关闭过冲（overshoot） |

手势拖拽要点（如列表拖拽排序）：拖动中元素紧跟指针并用占位提示落点；释放时结合位置与速度收拢到目标位，取消或越界时平滑退回原位；服务端保存失败须回滚顺序或提供明确重试，并同步提供键盘/按钮排序替代路径。

## 实现红线、反模式与检查

- **性能与生命周期**：优先动画化 `transform` 与 `opacity`，避免直接驱动 `height`/`top`/`width` 或在动画帧内交替读写布局引发抖动；关闭确定后**立即停止离场层接收点击与焦点**，待退出动画结束再卸载节点，焦点移回触发点或合理可见目标。
- **不加动画的场景**：阅读输入期间文字或按钮无故位移；缺少关闭入口的自动循环/视差；只有慢放才看得出、正常速度下反而闪烁拖沓的动效。

| 常见反模式 | 危害 | 修正做法 |
| --- | --- | --- |
| 每次触发都从第一帧重播或排队 | 快速连点时闪跳、阻塞操作 | 从当前计算状态直接插值转向最新目标 |
| 离场浮层仍能点击或困住焦点 | 误触遮挡、键盘死路 | 触发关闭即禁用其交互并转移焦点 |
| 全页面元素一刀切缩放/错峰入场 | 掩盖主次关系、拖慢高频任务 | 仅对有因果关系的目标元素做局部过渡 |
| 等动画播完才更新可访问状态 | 屏幕阅读器与快速操作状态滞后 | 语义状态与操作可用性按交互结果即时更新 |
| 把“减少动态效果”做成单纯加速位移 | 仍会引发眩晕或干扰 | 直接移除非必要空间位移，保留静态反馈（参考 [WCAG 2.2 2.3.3](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)） |

**检查方法**：优先在正常速度下实测连点、中途反向、键盘进出与 `prefers-reduced-motion`；无法实时观看时，可通过读取计算样式（`transition`/`transform-origin`）、截取开始/中途/连点关键帧及录制性能火焰图定位跳变与掉帧，并如实注明未验证的真机手感。

## 成对案例：同一桌面筛选侧面板

固定背景：桌面项目工具点击工具栏“筛选”打开含三个筛选项的侧栏，选完回到项目列表。

| 变量对比 | 具体方案与理由 | 代价、改判条件与验证重点 |
| --- | --- | --- |
| **1A：偶尔使用** | 侧栏从工具栏同侧短距离滑入、原路滑出，打开移入焦点、关闭回到按钮，用空间方向交代面板与列表关系。 | 多一次短暂过渡；若用户开始高频反复开关，应缩短或改为直出。正常速度检查开关与焦点归位。 |
| **1B：高频连续使用** | 侧栏立即出现与消失，靠静态边框、标题和按钮展开态交代层级，反复开关零动效等待。 | 空间来源感较弱；若新用户常误以为跳了新页面，仅加极短且不阻塞点击的提示。实测快速连开连关与纯键盘流畅度。 |
| **2A：偶发使用 + 默认系统偏好** | 采用 1A 的短距离进出，同时保留边框与按钮展开态等不依赖运动的静态线索。 | 若引起列表文字晃动则削弱位移。实测运动中途反向重开是否平滑衔接。 |
| **2B：偶发使用 + 开启减少动态效果** | 直接在最终位置显隐，彻底关闭滑入滑出位移（不强塞淡化动画凑数），靠边框、按钮展开态与焦点迁移说明状态。 | 无空间移动线索；若定位困难则强化按钮与面板的静态视觉关联而非恢复位移。在系统减少动态效果设置下实测无残留运动。 |
